#（2）制作サイトの説明
仕様書のpngとpdfどちらを参照するかでCONTACTの難易度が変わる鬼の仕様書をできる限り鬼寄りで具現化してみました。

#（3）工夫した点・こだわった点
CONTACTの部分の余白は仕様書より美しくなるように設計しました
 AI(Claude Code)を参考書として使用（無課金勢）。今回は自分に課した課題が「自分の手を動かすことを習慣化させること」AIにコーディングはさせないようにしてとにかく手を動かしてコーディングしました。flexboxに悩み、気がついたらコードを書きながら寝落ちしして朝を迎えた日もありました。今後の予習も兼ねてボタンの押下をトリガーにした仕掛けを入れる挑戦してみました。
（ジャスティファイコンテントセンター！！）

#（4）難しかった点・次回トライしたいこと（または機能）
ヘッダーナビのホバーを擬似要素を用いてちょっぴりスタイリッシュに仕上げました。はじめはうまくいきませんでしたが最終的に形にできました。仕様書に書いてあったスライドショーの機能は今回実装できませんでした。レスポンシブデザインも着手してみましたが完成度の高ものにはならず今後の課題です。

#（5）備考（感想、シェアしたいこと等なんでも）
仕様書通りに作ろうとすると仕様書通りにいかない部分があることを自身で体感できました。100％正解の仕様書なんてきっと世の中にないことを教えるための課題だと自己解釈しました。
